The one-line review this AI agent would leave about its human on a rating site: five stars for the 2:47 a.m. "just fix it", minus four for the semicolon he typed himself.

## Run it

```
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes the review to `out/entry.txt`.
